## R1 修复「保存颜色失败 HTTP 415」
- 现象：设置页勾「自动色」/改色即报 `HTTP 415 Expected request with Content-Type: application/json`。
- 根因：前端 `j()` 的 HDR() 只带 `X-Auth-Token`，fetch 带 string body 时默认 Content-Type 为 text/plain，被 axum `Json` extractor 拒绝。
- 修法：`j()` 凡有字符串 body 且未显式指定 Content-Type，自动补 `application/json`。
- 验收：测试节点浏览器里点复选框/调色板 → 无 alert；PUT /v1/colors 返回 200；刷新后配色保留。
- 状态：[x] 已实现并验收
- 验收记录：debug 双节点（18785/18795）浏览器点「自动色」复选框→无 alert；`/v1/colors` 读回已持久化；curl 无 Content-Type 与 text/plain 两种 PUT 均 200（后端 `colors_put` 同步换 `JsonAny` 宽容提取器）。

## R3 双层胶囊配色体系（用户口述规格，替换现有"border-left 细边"方案）
- 规格：外层 = 节点色系**深色胶囊容器**（大圆角），左侧留出一段**很粗的节点色圆弧**；
  容器内**嵌一个更小的 agent 胶囊**，靠右排；agent 胶囊用比节点更亮的柔色（不刺眼）。
- 层级铁律：节点色比 agent 色**深一档**（此前搞反：agent 深、节点亮）。
- 色阶：节点容器 hsl(H,45%,28%)、节点文字/圆点 hsl(H,55%,62%)、agent 内胶囊 hsl(H+135..244,60%,68%) 深字。
  手选色（COLORS 覆盖）时容器/内芯分别用覆盖值或按同规则派生。
- 应用位置（三处一致）：
  1. 对话记录/历史行的 agent 胶囊 `.idc`（改双层 DOM：外 span + 内 span）；
  2. 设置页配色预览胶囊（与 1 同一渲染）；
  3. 星图 agent 药丸 `.agt .dot`（外深色容器+内亮小胶囊+左侧粗弧）。
- 验收：三处截图目测「深色外托 + 左侧粗弧 + 内嵌靠右小胶囊」；同节点多 agent 色相可区分。
- 状态：[x] 已实现并验收
- 验收记录：三处统一公式（nodeCol 46%/30% 深容器、nodeHi 58%/66%、agCol 58%/72% 亮内芯，agent 色相=节点hue+140..239 按 agent_id 散列）；对话行 `.idc/.idci`、设置预览（与对话同一渲染）、星图 `.agt .dot` 外托 `--acn`+内芯 `.in` 均截图/几何确认；`justify-content:flex-end` 计算样式实测通过。
