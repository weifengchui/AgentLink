# Web 控制台需求单 · 2026-10-16 第五轮（消息星图）

范围：`web/starmap.html`（弹窗按钮/滚动条、布局、幽灵清理均在星图页内；总览页不动）。

## R1 星图出现不存在的节点/Agent（过期幽灵）

- 现象：星图上残留早已不在网里的节点圆和 agent 胶囊（历史里出现过一次就永远显示）。
- 根因：前端 `MACH` 为增量累积：`msgOf()`/`ensureEnd()` 只要历史消息提到某 node/agent 就建站台/胶囊，且 `loadTopo()` 只增不删；`byNode` 里节点不在 peers 表也照样 `ensureAll`。后端 fleet 视图虽有 ghost guard，但历史环/持久化里旧对端 id 仍在。
- 修法：以 `/v1/peers` ∪ 本机 为节点白名单、`/v1/fleet/agents` 为 agent 白名单，每轮 `loadTopo` 建立 `LIVE_N/LIVE_A`；`ensureEnd` 拒绝创建白名单外的端点；`loadTopo` 末尾删除 `MACH` 中已消失的节点及其胶囊；消息出口（`activeMsgs`/`chainFor`/`flyIn`）统一过滤指向幽灵端点的消息（与 `epHid` 同口径，保证 HUD=Σ徽章=卡组）。删除 `byNode` 不在 NODES 时的 `ensureAll` 分支。
- 验收：测试节点历史里发给一个伪造 node id 的消息 → 星图不再出现该站台/胶囊，HUD 窗口内计数不含这些消息；真实节点仍正常显示。
- 状态：☑（实测：伪造节点 ffffdeadbeef/111122223333 站台与消息全滤，HUD 计数不含幽灵；agent 胶囊最终口径=注册表 ∪ 窗口内活跃（growLive/mergeAgents），窗口外未注册 id 自动清退、在册闲置不误删）

## R2 弹窗 ‹ › 换组按钮移到窗外两侧 + 深色自定义滚动条

- 现象：上一组/下一组按钮现在悬浮在弹窗内部左右边缘（遮挡正文/列表），弹窗内滚动条是浏览器默认浅色宽条，与暗色主题不搭。
- 根因：`.gn` 是 `#viewer`（`overflow:hidden`）的子元素只能摆在内部；滚动条未定义样式。
- 修法：两个按钮移出 `#viewer` 到 body，改 `position:fixed`，JS 按 viewer 的 `getBoundingClientRect` 贴左/右外侧 12px（窗边空间放不下时才回退贴内侧），openViewer/换组/resize 时重算；为 `#vlist`/`#vmain` 加 webkit + Firefox(`scrollbar-color`) 细窄深色滚动条，thumb 随话题主题色 `--vc`。
- 状态：☑（实测：弹窗左缘 180/右缘 1100 时按钮贴 134/1112 窗外两侧各 12px，三组话题 ‹ › 循环切换正常；`posGNav` 按居中尺寸公式定位，空间不足回贴内侧；关闭时按钮隐藏；长文弹窗 1660>598 出深色细滚动条，thumb 随话题色）

## R3 卡组在节点上方时，鼠标路过节点导致卡片消失

- 现象：agent 消息组卡片摊在节点上方/侧上方，鼠标从胶囊移向卡片的路上经过节点站台感应区，卡片整体消失，点不到。
- 根因：`reveal(k)` 开头就把其它所有卡组收起；而节点站台 `.station`（150×150 感应盒）`pointerenter` 无条件调 `reveal(nodeKey)`——即使该节点一个卡片都没有（空卡组），也把正在悬停的 agent 卡组收掉了。
- 修法：`reveal(k)` 改为先 `buildDeck(k)`，只有当 k 自己真的有卡片要显示时才收起其它卡组；空卡组悬停不再杀伤别人的卡组（节点侧无卡片 → 路过无感）。
- 状态：☑（实测：CDP 模拟鼠标从胶囊纵穿节点感应区，卡组全程 alive 不消失；reveal 先建卡组、空卡组直接返回不杀伤别人，其它卡组 600ms scheduleHide 宽限可撤销）

## R4 默认分布尽量相互远离（布局算法调研 + 实现）

- 现象：默认环半径固定（0.28W×0.30H 椭圆），节点数变化时间距不可控：节点少时偏挤一侧/上下不均衡，节点多时相邻站点胶囊互踩。
- 调研结论：
  - Fruchterman-Reingold / 力导向（repulsion+spring）：适合静态链接图，但迭代结果依赖初值与轮数，每次轮询重建世界会抖动，且我们"宁可不显示不能错误"要求确定性——不采用；
  - 圆盘 Poisson 盘采样 / Farthest-Point（maximin）贪心：能最大化最小间距但点位不规整、无"本机居中、众星拱之"的星图语义——不采用；
  - 黄金角向日葵螺旋：确定性均铺圆盘，但近邻仍可能小于硬间距——不采用；
  - **同心环贪心（外环优先、每环按"弦长≥最小间距"定容量）**：确定性、可证明相邻站点圆心距≥阈值、天然保持本机居中语义——采用。
- 修法：`frRing(j,n)` 重写为环贪心：可用区=拖拽钳制框（x∈[130,W-130]、y∈staClamp），中心为本机；候选椭圆环半径比例 t=1.0/0.62/0.40/0.25，环容量 `cap=floor(π/asin(minSep/(2·r_eff·t)))`（r_eff=min(ax,ay) 保守取值），每环从 −90° 均分、逐环相位错开半格；`minSep=2·orbR()+150`（覆盖站台盒+胶囊轨道+标签带）。返回 px→分数坐标，`复位` 语义不变（清 STA/AGTP 重算）。
- 状态：☑（同心环贪心 layoutPlan 落地；minSep 随 R5 终值=2*(orbR()+44)+120；单节点实测居中无出界；多节点环距确定性待线上自然流量复验）

## R5 节点圆整体再缩小一档

- 现象：v0.4.19 收过的 46px orb 仍偏大，画面权重压过 agent 胶囊。
- 修法：站台盒 150→118；orb inset 52→40（直径 46→38）；ring/pulse inset 40→33；glyph 12→10px、短名分档收紧（>3 字符即缩字号，防出圆）；胶囊轨道 `orbR()` 46–66→40–56；拖拽钳制 130→110；截图 hexPath 86→66、标签偏移同步。
- 状态：☑（终值：站台感应盒 150→76px、orb 直径 38px、ring/pulse inset:12、glyph 10px、短名 5-7 字 6.5px 收紧、胶囊轨道 orbR()+44、hexPath 66；6 胶囊实测精确 60° 等角环布、半径一致、文字不溢出、视觉验收通过。initPos 改为每轮等角重排，手动拖过的胶囊（AGP 标记）保留原位）
