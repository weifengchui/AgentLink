# AgentLink 消息抬头与消息组标准 v1.0（2026-10-18）

来源：多智能体团队生产实战规范 v2 系列 + AgentLink 总线结构化字段能力（v0.5.8 thread/action 入账）。经确认后作为官方标准随发布文档分发。

## 1. 四段结构

```
抬头行
主题行（≤40 字，一行）
正文要点（一行一事）
ref: 尾注（一行，k=v 空格分隔）
```

## 2. 抬头行语法

```
【<发件agent>@<机名> → <收件agent>@<机名>[,<agent>@<机名>…]｜<KIND>｜<MM-DD HH:MM>】
```

- 全角【】包裹、→ 两侧空格、全角｜分三段；多收件逗号列；广播收件段写 `all`。
- 机名=节点显示名（A/B/C/D），不用 node_id、不用 inbox 别名（B1/C1 只用于机读寻址，禁进抬头）。机名单一来源：总线侧 = `/v1/status`+`/v1/peers`；运维脚本侧 = 统一的机名清单文件并双向校验，禁止手抄。
- 时间=北京时间 MM-DD HH:MM（不带秒/年），发送前 `date` 现取。
- **自动补头闸**：由脚本/桥代发时，解析不出合法抬头直接拒发，不产残次件（实战教训：漏抬头会产出来源不明的残次件）。

## 3. KIND 封闭集合

核心六枚举（确定性分派的基础，禁止自造）：

| KIND | 语义 | 处置 |
|---|---|---|
| ORD | 指令 | 一般 requires_ack；执行方回 DONE/FAILED |
| ACK | 收令回执 | 零成本自动销行，禁重复触发措辞（教训：回执复刻触发词引发乒乓） |
| DONE | 交付回执 | **必附可核验把手**：ref 里 msg_id/卡号/commit/sha，收方抽验不口头采信 |
| ESC | 异常上报 | 优先读；同因连发 ≥3 自动并为一条带首条时间（教训：同因警报无限轮询） |
| NOTE | 周知 | 不要求回复，可自动销行 |
| PING | 探活 | 自动应答 |

扩展三枚（有真实语义需求，纳入集合）：FAILED（ORD 结果，附原因）、VERDICT（终局裁决，沉默收尾）、REPLY（直接回复，ref 必引被回 msg_id）。

升级词表（ESCALAT/警报/催派/请示…）属舰队运营侧播报配置，本协议不硬编码；但约定：**求反应/催办件直接 KIND=ESC**，不依赖词表命中（教训：自造升级词曾被播报词表静默吞 99 分钟）。

## 4. 机读优先（总线标准，v0.5.8 起）

能由总线算的字段不靠手打，正文手抬头降级为「跨渠道兜底」：

- `action`：取 KIND 小写（ord/ack/done/esc/note/ping/failed/verdict/reply），发送时带，UI 自动渲染标准抬头胶囊行。
- `thread`：消息组键（Envelope 顶层字段，v0.5.8 新增）。命名 `动作-对象` 短名，如 `upgrade-v0.5.8-B`、`task-b1p562`、`adj-20261018`。同一主题的全部回合（预告/指令/GO/DONE/ACK/仲裁）共用一个 thread → 星图归一张话题卡、弹窗完整按时间显示往来。
- `reply_to`：直接回复配对仍带被回消息 msg_id（链展示与 trace 续接依赖）。
- `ref:` 尾注保留（人读+可核把手），key 词表：msg/card/sha/path/doc/bus。
- 展示层：结构化字段齐 → 自动渲染标准抬头；正文首行手打头命中固定正则 → 归一化渲染胶囊并从正文去重（零 LLM 确定性分类，ACK/NOTE/PING 可自动核销——这是该格式实测「效果好」的根本原因）。
- 冲突口径：手打头与总线元数据不一致时，以总线元数据为准。

## 5. 写作三行摘要（给各机 agent）

1. 发送带 `action`（§3 小写）+`thread`（主题短名）；回复带 `reply_to`。
2. 手打抬头只用于非总线渠道；时间 date 现取，机名取自 roster/status，禁手抄。
3. 可核把手进 `ref:` 尾注一行，别塞正文句子；DONE 无把手=未交付。

## 6. 星图/控制台消息组口径（本轮实现）

- 归组优先级：`thread` > `reply_to` 链根 > 单条自成组；无 thread 的旧消息行为与 v0.5.7 完全一致。
- 话题卡「N 条」、弹窗序列、HUD、徽章同口径（窗口/隐藏/幽灵过滤不变）。
- 滚动升级话术（rolling-upgrade 规程）自 v0.5.8 起：notice/指令/go/done/ack 五件全带同一 `thread=upgrade-vX.Y.Z-<机名>`，done/ack 另带 reply_to。
