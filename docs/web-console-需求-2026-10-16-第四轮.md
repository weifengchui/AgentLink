# Web 控制台需求台账 · 2026-10-16 第四轮

用户原话拆条：R1–R4 落 web/starmap.html，R5–R7 落 src/api.rs 内嵌控制台。逐条实施，验收后回填状态。

## R1 消息弹窗滚轮分区（星图）
- 现象/诉求：弹窗内鼠标滚轮永远在切「上一条/下一条」，右侧正文长内容根本滚不动，体验生硬。
- 根因：`viewer` 上单一 wheel 监听 `e.preventDefault();mv(...)`，不区分左列表/右正文。
- 修法：左侧 #vlist 滚轮＝逐格切消息（累积器阈值 53px 防一格跳多条，500ms 窗口重置）；右侧 #vmain 可滚且未到边界时放行原生滚动，到达上/下边界继续滚才切上/下一条；切换后正文回顶。
- 验收：弹窗内右区长正文先滚动、到底滚一下切下一条、到顶滚一下切上一条；左列表滚动即逐条切换；单格滚轮只跳一条。
- 状态：[ ]

## R2 弹窗两侧「上一组/下一组」按钮（星图）
- 现象/诉求：想在弹窗里直接换到相邻话题组，不用关闭弹窗再点另一张卡。
- 根因：openViewer 未记录所属实体 k，弹窗无话题组序列概念。
- 修法：VT 增加 k（卡组来源实体）；抽出 chainFor(tp,k) 复用开窗过滤；groupsFor(k) 排序即组序列；弹窗左右边缘悬浮 ‹ › 按钮（组数>1 才显示），点击在序列内环绕换组，主题色/--vc/链路高亮同步刷新；Shift+←/→ 同效。
- 验收：从某 agent 卡组开窗后点 › 直接换到该 agent 的下一个话题组并停在最新一条；组序列与悬停卡组顺序一致；单组时按钮隐藏。
- 状态：[ ]

## R3 节点圆圈收缩 + 悬停节点点亮其 agent 胶囊（星图）
- 现象/诉求：节点圆太大、胶囊离得远、归属感弱；悬停节点时其胶囊要有反应。
- 根因：orb 直径 62px、轨道半径 orbR 上限 112px，胶囊悬在远处；悬停仅出卡组，胶囊本身无状态。
- 修法：orb inset 44→52（直径 46px），ring/pulse inset 32→40，lab 上移补偿；glyph 字号 14→12px 且缩短名分档（≤5 正常 / 6–9 缩 10px / >9 截 5 字…）；orbR 上限 112→66，胶囊轨道贴近节点；applyLanes 末尾同步：悬停（或钉选）节点时该节点全部 .agt 加 .lit（brightness 1.22 + 加强辉光 + 停止呼吸闪烁），离开延时恢复。
- 验收：实测胶囊内缘距 ring 外缘间隙明显缩小；程序化断言悬停 station 后该机全部胶囊 classList 含 lit、其它机不含；圆圈/文字比例协调（vision 复核）。
- 状态：[ ]

## R5 左侧导航栏：折叠/展开 + 拖拽调宽 + 悬浮动效拖拽把手（控制台）
- 现象/诉求：220px 定宽挡内容；希望可收起、可拖宽，且拖拽把手可见、悬浮有动效。
- 修法：#app 列宽改 var(--sw)（默认 220）；sidebar 右缘加 #side-resize 把手（细竖条 + 中央小胶囊图标，hover 时变蓝加长脉冲动效）；按住拖动实时改宽（clamp 150–460，存 localStorage al_sbw）；单击（未拖动）切换折叠：56px 宽、导航项只留单字（总/节/A/对/配，title 悬浮提示），logo 只留圆点；折叠态存 al_sbc，刷新保留。
- 验收：拖把手宽度跟手且刷新后保持；单击把手折叠/展开；折叠时导航单字居中、hover 有完整提示；把手 hover 有动效（程序断言 class 计算样式 + vision）。

## R7 全面局部刷新（控制台）
- 现象/诉求：任何刷新都不应整页闪动。
- 根因/修面：
  1. j() 收到 401 曾 `location.reload()`（整页刷）→ 改为就地弹回 token 层（隐藏 #app、显示 #modal、toast 提示），refresh 在 token 层未关时直接跳过轮询。
  2. renderColorCfg 每 2s 无条件重写 #cf-colors 整个 innerHTML → 加 LAST.cf 签名，内容不变不重写。
  3. fillAgDl 每 2s 重写 datalist → 加 LAST.dl 签名。
  4. 其余（表格/下拉/历史/统计）本已有选择冻结 + 签名缓存，复核不新增整页重写路径。
- 验收：构造 401 后页面不 reload、token 层出现且不再轮询；配置页静置无输入焦点时配色区 DOM 节点不被重写（节点 identity 前后一致）；无新增 location.reload 调用点。
- 状态：[ ]
