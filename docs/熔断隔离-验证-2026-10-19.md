## 1. 交付内容

### 1.1 运行核 `src/circuit.rs`（新增）
- `Circuit`：每 mesh 引擎一份的进程内记账表（`node → NodeTaint`）。重启即清（与批次护栏同口径，纯内存，无常驻后台流）。
- `record_failure(cfg, node, now)`：滑窗（首失败锚定、超窗清零重计）失败计数；达到 `failures`（≥1 防零阈值歧义）→ 置 unschedulable `cooldown_secs` 秒，**清零窗口**（避免解除后二次即刻熔断）；冷却中再失败记 `AlreadyTainted`（不续期）。
- `is_tainted` / `active`：**读取时惰性过期**并移除条目——冷却到期自动恢复调度资格，无需后台清扫。
- 输出视图 `TaintView { node, reason, failures, remaining_secs }`（按节点字典序，供 API）。

### 1.2 引擎接线 `src/reconcile.rs`
- **归账口径（唯一记账点）**：`consume_event` 中仅当帧把任务**首次转入 Failed**（`ApplyOutcome::Transitioned { to: Failed }`）时，把失败记到**执行节点**名下（`from_agent` 所在节点，查 `Router::find_agent_node`，缺省取 envelope `from`）。
  - 关键拍板：重投递/更新类帧（`Updated`，如在线执行方未取件触发信箱重投）**不归账**——初版按「终态为 Failed」归账，实测被重投帧反复续期、永不恢复，已改定。
  - 引擎自身重试（`from_agent="engine"`）不计——否则引擎重投失败会错误熔断本节点。
- **隔离生效**：`dispatch_pending` 选点前过滤熔断节点（对任务规则不可见，比 `exclude_tags` 更硬），冷却到期自动回池。
- 触发时 `warn!`（含 node/cooldown_secs/unschedulable），窗口计数 debug 级。

### 1.3 配置 `engine.circuit`（加性，缺省关）
```json
"engine": { "circuit": { "enabled": false,
                           "failures": 3, "window_secs": 600, "cooldown_secs": 300 } }
```
serde default：老 `agentlink.json` 零改动可跑；`enabled=false` 不记账、不过滤、不产出任何视图。

### 1.4 观察面 `/v1/mesh/status`
`engine.circuit_taints`：仍在熔断中的节点数组（含 no-taint 空数组）——加性 JSON 键，缺省关不改变其余字段。

|---|------|------|

## 3. 兼容性
- 缺省关：不记账不过滤不输出，`/v1/health` features、`/v1/tasks` 投影、`/v1/tasks/{id}` 逐字节不变；老配置文件无需改动。
