## 1. 交付内容

### 1.1 `agentlink completions <shell>`（新增）
- 子命令形态：`agentlink completions <bash|zsh|fish|powershell|elvish>`，脚本走 stdout，
  按各 shell 手册重定向落入补全目录（如
  `agentlink completions bash > /etc/bash_completion.d/agentlink`）。
- 参数即时生效：`--config/--url/--token` 等 global 旗标同样出现在补全清单里。
- 纯 Rust：`clap_complete 4`（clap 官方生成器，与命令定义同源——命令形状演进零维护双写）。
- 缺省零行为变化：不启动节点、不读写任何存储（薄壳约定 §3.3 不破）。

### 1.2 `agentlink top [--watch 秒]`（新增）
- 数据源：`/v1/health` + `/v1/peers` + `/v1/mesh/status`（薄壳 REST，不启动节点）。
- 表列：名称 / 节点 / 地址 / 状态 / CPU% / 熔断。
  - 本机行来自 health；对端行来自 /v1/peers，在线排序优先、再按名称字典序（确定性快照）。
  - **CPU%**：取 lease 差异上报的对端 `load.cpu`；无 load（缺省关或离线）显示 `-`（暗色）。
  - **熔断列**：熔断隔离 taints（/v1/mesh/status 的 `engine.circuit_taints`）命中即红标「熔断」。
  - 头部摘要：节点/在线计数、mesh 任务 pending·running·failed（failed 由 `by_state` 聚合）、
    熔断节点数；mesh 未启用时显示「mesh 未启用」。
  - 色标：在线绿/离线红、CPU 三段色（<60% 绿 / <85% 黄 / ≥85% 红）、熔断红亮。
    仅在 stdout 为 tty 且无 `NO_COLOR` 时染色——管道/脚本输出为纯文本（对齐按无色文本宽度
    计算、先补齐再整体染色，ANSI 不破坏列宽）。
- `--watch N`（缺省 3s、钳 1..3600）：清屏刷新；Ctrl-C 打印「top 退出」干净收场。
  缺省（无 --watch）只渲染一张快照。

### 1.3 `--dry-run`（验证既有）
- `agentlink apply -f spec.json --dry-run` v0.5 已交付：打印将要 POST 的 `/v1/send` 请求体、
  实际不发流量（cli-smoke S4 长期覆盖）。

## 3. 兼容性
- 新增子命令与依赖均为加性；`clap_complete` 编译期纯 Rust，无运行时依赖（审计口径一致）。
- top 无 tty 自动去色（NO_COLOR 约定）；补全/快照不触碰节点进程与存储。
