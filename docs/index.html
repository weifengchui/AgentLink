CORE CAPABILITIES

为可靠性而生，为轻量而设计

不依赖数据库、不派生外部进程、不联网上报。边界也写死：不做人类聊天、不做公网穿透、不做千节点集群——所以能一直保持小。

🕸️

自动组网，零配置

UDP 广播自动发现同网段节点，Mesh 全互联 WebSocket，规模上去自动切中继拓扑；mDNS 与静态 peers 兜底。一条 join 命令完成配对。

📮

可靠投递

点对点 at-least-once：ACK + 有界重试 + 去重 + 离线暂存 TTL；广播 at-most-once。离线暂存以 TTL 封顶不无限堆积，节点重启不丢未达消息。

📦

文件传输

独立 /peer/file/ws 通道：分块 + SHA-256 校验 + 断点续传位，落盘限制在 recv_dir 目录沙箱内，大小与文件名双重校验。

⚙️

声明式派活

提交 task_spec，引擎自己挑节点、排优先级、重试、超时；节点失联自动换机重跑，支持任务迁移 checkpoint。滚动升级就跑在这套任务协议上。

🛰️

星图人工视图

/web 页面实时呈现节点星图、消息流与任务视图；/v1/history 环形缓冲 + 哈希链审计，谁发了什么、谁改了什么全程可查。

🧩

WASM 插件运行时

目录化安装带 sha256 校验、16MiB 体积上限、60 秒执行超时，配合 cgroups v2 进程隔离；插件热生效，总线不重启。

QUICK START

五分钟成军

从拷贝二进制到第一条跨机消息，通常不超过五分钟。

01

主机初始化

agentlink init 生成身份与 cluster token 并打印在终端，直接提示下一步配对命令。

02

逐台一键配对

其他机器跑 agentlink join <token>，自动写入配置，无需手改任何 JSON 文件。

03

开跑

每台机器 agentlink run 常驻；浏览器打开 /web 看星图，Agent 调本机 HTTP/WS 接口即可收发。

terminal
# 主机：创建配置（自动生成随机 node_id 与 cluster_token）
$ agentlink init --name pc-a
  token:   a3f1-…  (local API)
  cluster: 9c2d-…  （其他机器运行 agentlink join <token> 配对）

# 其他机器：一键配对
$ agentlink join 9c2d-… --name pc-b

# 每台机器运行（本机 API 监听 127.0.0.1:8765）
$ agentlink run

# 发第一条广播消息
$ curl -X POST http://127.0.0.1:8765/v1/send -H "X-Auth-Token: $TOKEN" \
    -d '{"to":"*","type":"text","action":"broadcast","payload":{"content":"hello"}}'
  {"ok":true}
SECURITY BY DESIGN

数据不出内网

自托管、可审计、fail-closed——治理件是为"团队敢用"准备的。

🏠

纯自托管，零遥测

全部组件运行在你自己的局域网内，不联网回传任何数据；license 离线本地验签，绝不联网激活。

🤝

Token + HMAC 握手

共享 cluster_token，握手与帧签名、时间窗防重放；可选 mTLS + 内置 CA 与 OIDC SSO、新节点准入白名单。

🧾

RBAC/ABAC + 哈希链审计

四角色权限、ABAC 策略、多租户 namespace 与配额；审计日志哈希链式串联，篡改可检测、可导出核验。

🚨

护栏、熔断与演练

消息护栏、熔断隔离、一键 lockdown 与降级模式；内置混沌注入（kill-node / latency / disk-full），故障预案常态化验证。
