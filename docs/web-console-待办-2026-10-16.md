# Web 控制台待办清单（2026-10-16 用户反馈，v0.4.16 升级后）

开发排期依据本清单；逐条验收后勾选。

## 1. 升级后最新版本页面混乱（回归 bug）
- 右侧区域变成"整体"一块，且条目次序混乱。需对照 v0.4.14 的布局恢复分栏与排序。

## 2. 节点可改名 + 大屏显示友好名
- 允许在页面上修改节点名称（当前节点 name 多为 IP，如 `192.168.1.50`）。
- 消息大屏、星图等所有展示位改用该名称。node_id 仍是唯一硬标识，改名不影响寻址。

## 3. 节点配色体系
- 每个节点分配一个稳定且互不相同的颜色（按 node_id 哈希固定分配，避免每次刷新变色）。
- 该节点对应的 agent 胶囊：加该节点颜色的包边或前脸，一眼区分 agent 来自哪个节点。
- 对话记录里的 agent 胶囊同样处理。
- 层级要求：节点颜色比 agent 胶囊自身颜色更深一档，保证胶囊上的节点标识突出。

## 4. 对话记录局部刷新
- 对话记录更新只刷新其列表区域，禁止整页刷新（现状：筛选下拉框莫名消失，无法正常使用）。
- 对话记录列表分页组件支持选择每页条数（如 20/50/100）。

## 5. 总览页自适应
- 总览页内容充满整个页面宽度，随窗口自适应，不留大块空白。

## 6. 消息星图交互
- 6.1 悬停节点或 agent 时：
  - 消息组卡片保持在光标附近；
  - 立即隐藏其他不相关的卡片/连线，只保留当前应呈现的卡片、连线与目标；
  - 消息组卡片上的消息数量必须准确；
  - 鼠标移到消息组卡片上时，卡片左右位置不动，只允许上下拉伸（防抖动）；
  - 悬停 agent / 节点 / 卡片时，相关连线要确实高亮可见（当前看不到）。
