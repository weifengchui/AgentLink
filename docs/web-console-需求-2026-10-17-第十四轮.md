## R1 星图：拖动 agent 胶囊时其他胶囊自动避让

- 需求：星图大屏拖动某个 agent 胶囊时，压到/贴近它的其他 agent 胶囊自动让开，松手后各自滑回原位；被拖胶囊的落位保持现有 AGP 定版口径不变。
- 方案（拍板：瞬时磁避让，不持久化）：
  - 新增临时偏移层 `AVO[k]={x,y}`（stage 像素，叠加在 AGTP 之上），`agPos()` 出口统一叠加 → 连线、粒子、卡组（posDwrap）自动跟随，视觉与数据恒一致。
  - 目标偏移 `AVOT` 在拖动的每次 pointermove 重算：以被拖胶囊矩形（外扩 margin 6px）为唯一斥力源，其余胶囊沿"斥力中心→自身基准位"射线推出到不重叠，单枚偏移上限 120px；基准已不重叠则目标 0。
  - rAF 滑移循环 `avTick`：`AVO += (AVOT−AVO)*0.3`，全部收敛后停循环；pointerup 把目标清零 → 其他胶囊平滑回位。
  - AVO/AVOT 绝不写入 AGTP/AGP；世界重建（buildWorld）、复位按钮（bReset）同步清空 AVO/AVOT 与尺寸缓存 AGSZ。
  - 胶囊尺寸缓存 AGSZ 用 `.dot` 的 offsetWidth/offsetHeight（构建后惰性测量），避让几何纯 JS 计算，不在 move 中读 DOM rect（防布局抖动）。
- 验收：
  1. 同环 ≥3 胶囊：拖动其中一枚绕环半圈，全程其余胶囊矩形与被拖胶囊矩形（含 margin）零重叠；远离者不位移。
  2. 松手 600ms 内其余胶囊回到拖前基准位（±1px），被拖胶囊停在新环角且 AGP 标记保留。
  3. 避让期间连线端点与胶囊中心同帧一致（±2px），无脱线。
  4. 站点拖拽、单击钉选/取消、复位、悬停卡组回归全部不变。
  5. node --check 通过；隔离测试节点（187xx）实机 + 真实 CDP 鼠标路径验证截图存档。
- 状态：☑ 完成（2026-10-17）。验收记录：本机 B 预览构建热换件（20:37，含工作树避让代码）用户实机拖拽验证，20:42 确认「没问题了」放行发版；发版前复验 node --check 绿（单 script 块 48229B）、避让标记在源与构建中齐全（AVO×30/AVOT×14/avTick×4/AGSZ×5）。CDP 逐断言截图存档为开发会话遗留项，不阻塞 v0.5.6。
