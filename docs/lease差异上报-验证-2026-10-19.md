# v0.6 P1 Lease 心跳 + 阈值差异上报 — 实现与验证（2026-10-19）

对应路线图 v0.6：「**Lease 心跳 + 阈值差异上报（CPU±5% 才发 Full Status）**【设计案 §5.1】」——
10~30 台阶段用「差异化的 Full Status」替代全网格高频广播，控制保证转发的负载信息量。

---

## 1. 语义

- **缺省关闭**（`lease.enabled=false`，serde zero-value）：任务不 spawn、**零新增流量**，
  `/v1/peers` 的 `load` 字段**不存在**（`skip_serializing_if=None`），默认态逐字节零变化。
- **开启后**：每 `interval_secs`（默认 10s）采一次本机 CPU：
  - 变化 ≥ `cpu_threshold_pct`（默认 5，「±5% 才发」）或**首次采样** → 发 Full Status 帧
    （`ctrl/lease`，payload 带 `cpu` 0..=100）；
  - 阈值内 → **静默**（不发帧，链路活性沿用既有会话心跳/discovery）；
  - 长时间静默时按 `bare_beat_secs`（默认 60s，0=禁用）补一个**裸 lease 心跳**（无负载字段），
    只刷对端 `last_seen`，不清既有负载。
- **新对端入网补推**：hello 握手注册完成后，若本机已宣告过负载即补推一次快照——
  防止「对端晚于首轮 Full 注册」的空窗（空闲机上阈值内永不重发，否则要等下次跨越）。
- **繁重差异判定是纯函数**（`lease::decide`）：首拍必发 Full（无基准）；采样失败
  永不发 Full；阈值有效值 `max(t,1)` 防 0 抖动全量风暴。

## 2. 采样本（`src/load.rs`，零新依赖）

形态约束（单二进制 / 纯 Rust / 无 C）下的实现：

| 平台 | 方式 | 备注 |
|---|---|---|
| Linux | `/proc/stat` 首行两次读取差分（200ms 间隔，`idle+iowait` 计入 idle） | 原生采样，精度最好 |
| Windows | `wmic cpu get loadpercentage` → 失败退 PowerShell `Get-CimInstance` | 一条子进程 per 采样 |
| macOS | `top -l 1 -n 0` 解析 `CPU usage: x% user, y% sys` | 同上 |
| 其它/失败 | `None` | 上报层退化为「永不 Full + 裸心跳兜底」 |

**采样是阻塞调用**（Linux 200ms sleep），放在 `tokio::task::spawn_blocking`，
不占异步执行器。仅在 `lease.enabled=true` 时被调用。

## 3. 帧与数据面

- **帧**：`Envelope{ kind:"ctrl", action:"lease", payload:{cpu} }`（构造器 `Envelope::lease`）。
  加性 ctrl 帧 —— 旧节点在 `conn::handle_text` 底部分支按「未知 ctrl 帧」直接忽略，
  混版本舰队零破坏。入站侧要求先经 hello 握手（未握手帧忽略），登记进
  `PeerTable.set_load`（bare 只刷 `last_seen`，full 更新 `PeerLoad{cpu,ts}`）。
- **观测**：
  - `/v1/peers`：对端条目加 `load: {cpu, ts}`（纯加性、缺省无 key）；
  - `/v1/metrics`：`agentlink_peer_cpu_percent{node="…"}` gauge（仅 online 且发过
    Full 的节点产出 series；未启用 lease 的集群**零新增 series**，导出形态不变）。
- **不做**：CPU 不参与调度打分（bin-packing 仍是额度最大优先）；差异判定只在
  出站侧（每个节点自己决定要不要发），接收侧只是台账登记。

## 4. 配置

```json
"lease": {
  "enabled": true,
  "interval_secs": 10,        // 采样与差异判定周期
  "cpu_threshold_pct": 5,     // ±5% 才发 Full Status（设计案原话）
  "bare_beat_secs": 60        // 裸 lease 心跳最长静默间隔（0=禁用）
}
```

## 5. 单测（`cargo test`，108/0）

- `load.rs` 3 项：/proc/stat 解析（含 idle+iowait 语义）、短行/非聚合行拒绝、
  差分数学（全忙/全闲/一般/计数器回绕饱和 0）;
- `lease.rs` 2 项：`decide` 阈值语义全谱（首次必发 / ≥阈值 / <阈值静默 /
  采样失败 / bare 兜底 / threshold=0 与 bare=0 档位）、lease 帧加性往返;
- `config.rs` +1：lease 段缺省与显式覆盖；
- `peer.rs` +1：`load` 加性 —— 缺省视图 JSON **无 key**；full 登记 / bare 覆盖原值。

## 9. 边界与后续

- 采样目前**只覆盖 CPU**；mem/磁盘等后续按需扩展 `PeerLoad`（加性）。
- 远端节点 tags/负载参与调度打分（bin-packing 侧）甪 M3 既有标注——本包提供数据源，
  消费侧留给盾「熔断隔离」/调度演进。
- 裸心跳与既有会话心跳并存的成本：每 `bare_beat_secs` 一帧 ~200B，30 机网格
  每节点 ≈ 29 帧/分钟，可忽略（若要更省，`bare_beat_secs` 收大或置 0 完全复用
  既有心跳）。
