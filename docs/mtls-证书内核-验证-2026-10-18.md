## 1. 存储与产物

默认落在 `<data_dir>/mtls/`（`mtls.ca_cert`/`mtls.ca_key` 可改写 CA 路径）：

| 文件 | 内容 |
|---|---|
| `ca.pem` / `ca.key` | 集群根 CA（ECDSA P-256，自签，10 年）；CA 不变则全网信任不变 |
| `node.pem` / `node.key` | 本机节点证书（由 CA 签发，`ServerAuth+ClientAuth`）+ 私钥 |
| `node.expiry` | 节点证书到期时间（Unix 秒），用于轮转判定 |

Unix 上私钥文件尽力收紧为 `0600`。

## 2. 设计取舍：不引入 X.509 解析依赖

CA 仅作「签发者」使用——`rcgen` 的 `serialize_pem_with_signer` 只读取 CA 的
**issuer DN + 签名算法 + 私钥**，这三者都是本模块自持的常量（`CN=AgentLink CA`、
P-256）与落盘私钥。因此重签发节点证书**无需回读解析 CA 证书**，节点到期时间
单独落 `node.expiry`。代价：只依赖 `rcgen`（默认 `pem` feature），不启用
`x509-parser`，保持依赖面最小、Windows-gnu 交叉编译友好、单二进制零运行时依赖。

## 3. 生成与轮转语义（`src/mtls.rs`）

- `MtlsManager::load_or_create(config, data_dir)`：
  - CA 四件套中 CA 可读 → 复用；否则新生成整条链（CA + 节点）。
  - 节点证书齐全且**未进入轮转窗口** → 复用；否则用现有 CA 重签（**CA 不变**）。
  - 节点证书缺失/损坏 → 沿用现有 CA 重签，**不换 CA**（不打断全网信任）。
- 轮转判定 `needs_rotation_at(expiry, window, now) = (expiry - now) <= window`：
  距到期不足 `cert_rotate_interval_seconds`（默认 6h）或已过期 → 需重签。
- `rotate_node_cert()`：用现有 CA 立即重签并落盘（CA 指纹不变）。

拍板默认（`MtlsConfig`）：`enabled=false`（LAN 明文）、`cert_ttl_days=1`（24h）、
`cert_rotate_interval_seconds=21600`（6h）。`MtlsConfig` 手写 `Default`，
保证 `Config::generate` 与 serde 缺省一致（不再是 0 天 / 0 秒）。

## 4. CLI 一键启用（`agentlink mtls`）

```bash
agentlink mtls              # 等价 --show：打印状态/路径/指纹/到期
agentlink mtls --enable     # 生成/加载证书并把 mtls.enabled 置 true（一键开启）
agentlink mtls --disable    # 写回 enabled=false（保留证书文件）
agentlink mtls --rotate     # 立即轮转节点证书（CA 不变）
```

`--enable`/`--disable` 互斥；`--enable` 与 `--rotate` 可组合（先轮转再开启）。
节点启动（`agentlink run`）在 `mtls.enabled=true` 时确保证书就绪并记录
`mtls: certificates ready`（含 CA 指纹/到期）；失败只告警不阻断启动。

实测（隔离目录）：

```
$ agentlink --config ./agentlink.json mtls --enable
mTLS: enabled
  CA cert:     .../mtls/ca.pem  sha256=82df2009...cb437
  node cert:   .../mtls/node.pem  sha256=df9eadaa...46e005
  node expiry: 2026-10-19T15:34:16Z
  ttl:         1 天（轮转窗口 21600s）
$ agentlink ... mtls --rotate          # 节点指纹变化、CA 指纹不变
```

## 5. 单测（`cargo test`，82 passed / 0 failed）

`src/mtls.rs` 6 项（各自独立临时目录，避免并行互踩）：

| 用例 | 断言 |
|---|---|
| `mtls_generates_then_reloads_same_ca` | 首生成非空；二次加载 CA/节点指纹均不变；新鲜证书 `needs_rotation()=false` |
| `mtls_rotation_keeps_ca_but_changes_node` | 轮转后 CA 指纹不变、节点指纹变化，且新节点证书已落盘（重载一致） |
| `mtls_needs_rotation_inside_window` | 窗口内/窗口外/已过期三种判定 |
| `mtls_rotate_interval_triggers_reissue_on_load` | 窗口 > TTL 时每次加载都重签、但复用同一 CA |
| `mtls_honors_custom_ca_paths` | `ca_cert`/`ca_key` 自定义路径生效，文件落在指定处 |
| `mtls_recovers_from_missing_node_cert` | 删节点证书后重载：沿用原 CA 重签（CA 指纹不变） |

`src/config.rs` 新增 `mtls_section_defaults_and_partial_fields`：无 mtls 段 /
只写 enabled / 显式自定义 ttl·窗口·CA 路径 / `Config::generate` 默认，四形态断言；
并在既有 `mesh_section_absent_defaults_off` 的老配置（无 mtls 段）上补 mtls 默认断言。

门禁：`cargo fmt --all` + `cargo clippy -- -D warnings` 零告警。
